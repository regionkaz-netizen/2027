# WAKASI Video Studio

Исходники Instagram Reels для WAKASI Event Games. Первый шаблон: **New Year 2026–2027**, 15 секунд, 1080×1920, 30 fps, premium navy/gold.

## Запуск

```bash
npm install
npm run dev
```

Для MP4:

```bash
npm run render
```

Файл сохранится в `out/wakasi-new-year-reel.mp4`. Нужны Node.js и поддерживаемая Remotion версия. Шаблон содержит типографическую анимацию; коммерческие кадры шоу и музыка не включены.
